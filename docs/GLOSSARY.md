# Glossary

The vocabulary used to tag concepts. These definitions are what the style card shows
when you hover a tag. In code they live in `src/content/glossary.ts` as typed lists, so
`meta.ts` can only use terms defined here.

## Visual descriptors

| Term | What it actually means |
| --- | --- |
| Clean | Little unnecessary clutter; elements are easy to distinguish. |
| Modern | Reflects contemporary design conventions, such as current typography, layouts, and interaction patterns. |
| Premium | Communicates high quality or exclusivity through visual presentation and content. |
| Vibrant | Energetic use of saturated colors, imagery, and contrast. |
| Muted | Uses subdued, less saturated colors. |
| Cohesive | Colors, typography, imagery, and components feel like they belong together. |
| Consistent | The same design rules and patterns are applied throughout the site. |
| Airy | Uses generous spacing to make content feel open rather than crowded. |
| Dense | Displays a large amount of information in a relatively small space. |
| High-contrast | Creates strong visual differences, such as light text on a dark background. |

## UX terms

| Term | Meaning |
| --- | --- |
| Frictionless | Removes unnecessary steps, obstacles, or confusion from a task. |
| Engaging | Holds the visitor's interest and encourages interaction. |
| Discoverable | Important features and information are easy to find. |
| Scannable | Users can quickly understand a page by looking at headings, lists, and highlighted information. |
| Accessible | Usable by people with a broad range of abilities and assistive technologies. |
| User-centric | Decisions are based on user needs and behavior rather than just aesthetics or business preferences. |
| Information architecture | How information is organized, categorized, and connected across the website. |
| Visual hierarchy | How size, position, color, and contrast indicate what users should notice first. |
| Call to action | An element that prompts a user to act, such as "Contact Us" or "Book Now." |
| User flow | The sequence of steps someone takes to accomplish a task on the site. |

## Craft terms (used in "How it's built")

Not tags, but terms that show up in style card bullets. Worth knowing.

| Term | Meaning |
| --- | --- |
| Grid | The invisible columns and rows that elements align to. |
| Whitespace | Empty space around and between elements; "negative space". |
| Type scale | A fixed set of text sizes that relate to each other by a ratio. |
| Tracking | Even spacing added or removed between all letters in a word or line. |
| Leading | The vertical space between lines of text (CSS `line-height`). |
| Serif / sans-serif | Fonts with / without small strokes at the ends of letters. |
| Display type | A typeface designed for large sizes, often too decorative for body text. |
| Accent color | A single strong color reserved for what matters most, often the CTA. |
| Easing | How an animation speeds up and slows down over its duration. |
| Spring | Motion driven by physics (stiffness, damping) instead of a fixed duration. |
| Parallax | Layers moving at different speeds while scrolling, to suggest depth. |
| Above the fold | What's visible before the visitor scrolls. |
